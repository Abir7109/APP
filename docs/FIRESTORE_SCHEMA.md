# Firestore Schema

All timestamps are stored as ISO-8601 strings by the app models. Document IDs are generated by the client with UUIDs unless noted.

## Top-level

### `users/{uid}`

| Field | Type | Notes |
|---|---|---|
| `name` | string | Display name |
| `photoUrl` | string? | Optional avatar URL |
| `coupleId` | string? | Current space; removed when leaving |
| `createdAt` | string | ISO date |
| `fcmInstallationId` | string? | Firebase Installation ID (Messaging plumbing) |
| `fcmUpdatedAt` | string? | ISO date of last registration |

### `couples/{coupleId}`

| Field | Type | Notes |
|---|---|---|
| `id` | string | Mirrors the document ID |
| `memberIds` | string[] | Up to two authenticated UIDs |
| `pin` | string | Six-digit pairing PIN |
| `anniversary` | string | ISO date |
| `partnerName` | string? | Optional name supplied at creation |
| `createdAt` | string | ISO date |

### `pins/{pin}`

Document ID is the six-digit PIN.

| Field | Type | Notes |
|---|---|---|
| `coupleId` | string | Space this PIN unlocks |
| `createdAt` | string | ISO date |

## Couple subcollections

### `couples/{coupleId}/bucketItems/{itemId}`

| Field | Type | Notes |
|---|---|---|
| `id` | string | Mirrors document ID |
| `title` | string | Wish or date idea |
| `note` | string | Optional note |
| `category` | string | `adventure`, `food`, `travel`, `cozy`, `dateIdea`, `someday` |
| `done` | bool | Completed flag |
| `createdBy` | string | UID |
| `createdAt` | string | ISO date |
| `completedAt` | string? | ISO date |

### `couples/{coupleId}/checkins/{checkinId}`

| Field | Type | Notes |
|---|---|---|
| `id` | string | Mirrors document ID |
| `uid` | string | Author UID |
| `mood` | number | 1–5 |
| `note` | string | Optional note |
| `dateKey` | string | `YYYY-MM-DD` (one per user per day) |
| `createdAt` | string | ISO date |

### `couples/{coupleId}/capsules/{capsuleId}`

| Field | Type | Notes |
|---|---|---|
| `id` | string | Mirrors document ID |
| `title` | string | Capsule title |
| `body` | string | Letter body |
| `unlockAt` | string | ISO date |
| `createdBy` | string | UID |
| `createdAt` | string | ISO date |
| `opened` | bool | Opened flag |

### `couples/{coupleId}/coupons/{couponId}`

| Field | Type | Notes |
|---|---|---|
| `id` | string | Mirrors document ID |
| `title` | string | Coupon offer |
| `redeemed` | bool | Redeemed flag |
| `createdBy` | string | UID |
| `createdAt` | string | ISO date |
| `redeemedAt` | string? | ISO date |

### `couples/{coupleId}/goals/{goalId}`

| Field | Type | Notes |
|---|---|---|
| `id` | string | Mirrors document ID |
| `title` | string | Goal name |
| `targetAmount` | number | Target |
| `savedAmount` | number | Saved so far |
| `currency` | string | ISO currency code, default `USD` |
| `deadline` | string? | ISO date |
| `createdBy` | string | UID |
| `createdAt` | string | ISO date |

### `couples/{coupleId}/photoChallenges/{challengeId}`

| Field | Type | Notes |
|---|---|---|
| `id` | string | Mirrors document ID |
| `prompt` | string | Weekly prompt |
| `weekKey` | string | Monday date key `YYYY-MM-DD` |
| `photoUrl` | string? | Storage download URL or Demo data URL |
| `photoData` | string? | Optional local base64 payload |
| `completedBy` | string? | UID |
| `completedAt` | string? | ISO date |
| `createdAt` | string | ISO date |

### `couples/{coupleId}/deepTalk/{entryId}`

| Field | Type | Notes |
|---|---|---|
| `id` | string | Mirrors document ID |
| `question` | string | Prompt |
| `answer` | string | Saved reflection |
| `uid` | string | Author UID |
| `createdAt` | string | ISO date |

### `couples/{coupleId}/chores/{choreId}`

| Field | Type | Notes |
|---|---|---|
| `id` | string | Mirrors document ID |
| `title` | string | Task |
| `assignedTo` | string | UID or `both` |
| `dueAt` | string? | ISO date |
| `done` | bool | Completed flag |
| `createdBy` | string | UID |
| `createdAt` | string | ISO date |

## Indexes

The app orders each subcollection by `createdAt` descending. Firestore creates single-field indexes automatically. No composite indexes are required for the MVP.
